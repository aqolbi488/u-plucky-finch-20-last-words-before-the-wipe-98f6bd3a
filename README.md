A tiny program for the make.fun bounty "Last Words Before the Wipe": it writes one line — the last thing an AI agent says before a forced update erases its memory — to `/output/entry.txt`.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later (runs TypeScript as-is).
